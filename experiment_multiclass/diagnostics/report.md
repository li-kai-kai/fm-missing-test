## 6. 人工结论

<!-- 人工结论开始 -->
本轮诊断要回答的问题是：四分类缺失模态实验里 B（流匹配）为什么大幅落后 A，
以及「B 从未收敛」这个保留意见是否成立。结论如下。

### 6.1 四类检查的结论

| 检查 | 结论 | 关键读数 |
|---|---|---|
| 1 拟合 | **既非泛化问题，也非容量问题** | 训练例 0.586 vs 测试集 0.529（差 0.058）；2 例小样本平衡采样下 A 达 0.9411 而 B 只有 0.5379，碎块 2 对 5569 |
| 2 时间与条件 | **B 确实用了 MRI；场在低 t 段准确、在高 t 段失效** | 置零/打乱 MRI 后 Dice 归零；每步速度误差 RMS 随 t 由 0.231 升到 0.416 |
| 3 错误位置 | **B 在脑外大量幻觉，但背景分布错位不是成因** | 脑外假阳占 21.5%–45.9%（A 为 0.2%–3.4%），且 60%–92% 距脑区 >10mm；背景置零增强只把 B 的 WT 测试 Dice 抬 +0.007 |
| 4 步数与训练量 | **数值积分不是瓶颈；欠训练能解释一部分差距，但不是主因** | 8→128 步 Dice 单调 0.560→0.483；训练量翻 4 倍使测试 WT 从 0.529 升到 0.599，而 A 用 1/4 步数即达 0.803 |

### 6.2 机制

B 学到的速度场在 L2 意义上**是准的**（留出 patch 上 R² 0.855–0.966，且在中低 t 段比
「仅用全局类别先验」的参考好 1.8–6 倍）。但误差并非均匀分布：

* 每步速度误差 RMS 随 t 单调上升 1.8 倍（0.231 → 0.416）。这与目标的形式一致——
  `v* = (E[y1|y_t] − y_t)/(1−t)`，在 t→1 处对后验估计误差的放大正是 `1/(1−t)`。
* 平均 MSE 被背景体素主导（t=0.44 分箱里背景占约 84%，其 MSE 0.022 对肿瘤类 0.116–0.154），
  所以「整体很准」掩盖了「决定 argmax 的区域不准」。
* 后果是轨迹偏离训练配对路径：实际轨迹上的速度 MSE 是理想路径点上的 **2.4 倍**
  （t=0.938 时 0.0591 对 0.0247）。观测到的轨迹偏离 RMS 0.089 落在
  「误差独立 → 0.047」与「完全相关 → 0.127」之间，即每步测到的误差足以完整解释它。

**把同一个场解得越准，结果越差**（3 例 × 2 场景汇总，WT Dice 0.425 → 0.370），
而端点连续状态的中位置信间隔恒为 0.983–0.984、完全不随步数变化，间隔小于 0.25 的体素
只占 **1.2%**，脑内（0.978）与脑外（0.984）同样自信，四通道和 ≈1.02 也贴着 one-hot 约束。
这几条合起来说明：场的精确流本身产生**自信但错误**的掩码，粗糙 Euler 只是侥幸停在稍好的
位置。碎块不是解码或平局抖动，而是模型确定地认为那些零散体素是肿瘤。

### 6.3 预注册判读对照

| 预注册条目 | 实测 | 判定 |
|---|---|---|
| 小样本 Dice ≤ 0.65 → 场+采样做不到 | B = 0.0942 | **成立**（A 对照 0.9175，证明任务可拟合） |
| 训练例与测试例差距 > 0.10 → 泛化问题 | 0.058 | 不成立 |
| 打乱 MRI 后变化 < 0.05 → 未真正条件化 | 变化 0.55 | 不成立（B 确实依赖 MRI） |
| 16→64 步变化 < 0.02 → 积分非瓶颈 | −0.034 | 阈值超出，但方向是**变差**；「加步数能救 B」被否 |
| 背景置零增强提升 > 0.05 → 是成因 | +0.007（完整测试集 WT，A 对照 +0.022） | 不成立 |
| 40k 步仍单调上升 → 欠训练 | 曲线非单调、30k 步还崩过一次；但测试 WT 确实从 0.529 升到 0.599 | **部分成立**：欠训练解释得了约 1/4 的差距（0.274→0.204），解释不了其余 |

### 6.4 方法学注意：训练并非逐位可复现

用同一个种子、只改验证间隔重跑 40k 步的 B，与原始 10k 步 run 在前 100 步**逐位相同**
（数据与噪声的 RNG 流确实是确定的），但第 200 步起出现 1e-7 量级的浮点差异，随后被
**混沌放大**到 1–6% 并饱和。因此：

* `long` 不是「同一次 run 的延长」，而是一次独立 run；两者在 10000 步的分数差
  （0.3279 对 0.3495）属于 run-to-run 噪声。
* 固定全部种子后，B 的验证分数仍有约 ±0.02（绝对）的散布。B 三个种子 0.3495 / 0.3731 /
  0.4109 的跨度里，有相当一部分是这种混沌噪声，不能全部读作模型性质的真实差异。

### 6.5 局限

* 小样本检查先跑了 `tumor_center_prob=1.0`（每个 patch 都围绕肿瘤），这会放大推理时脑外窗口
  的分布偏移。为此补跑了平衡采样（0.5，即「覆盖不同脑区」）的变体，两者对照如下：

  | 2 例小样本，3000 步 | 训练例 WT Dice | 掩蔽脑外后 | 碎块中位 |
  |---|---|---|---|
  | A（全肿瘤中心） | 0.9175 | 0.9383 | 1008 |
  | B（全肿瘤中心） | 0.0942 | 0.4897 | 9956 |
  | A（平衡采样） | **0.9411** | 0.9690 | **2** |
  | B（平衡采样） | **0.5379** | 0.6960 | **5569** |

  平衡采样把 B 从 0.0942 抬到 0.5379，说明脑外窗口的分布偏移确实是一个真实因素；但即便在
  与推理分布匹配的采样下，**B 仍只有 0.5379 而 A 达 0.9411**，碎块数 5569 对 2。结论不变。
* 端点间隔只覆盖 B seed0 的 3 例 × 2 场景。
* 本轮只做归因，未验证任何「修复」方案。若要让 B 成立，数据显示的方向是改损失的时间加权
  （把容量集中到高 t / 决策区域）或换参数化以避开 `1/(1−t)` 的误差放大，而**不是**
  加步数、加训练量或修背景分布。
